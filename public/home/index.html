What it is

Every race has keys. We track every one.

Presidential races aren't decided on Election Day. They're decided in hundreds of smaller moments: a trip to New Hampshire, a book tour, a fundraising quarter, a debate night, a governor's endorsement. Unlock The Count tracks those moments as they happen and shows what each one is worth.

Every candidate gets an Index score for where they stand and how viable they are, and a Launch Watch reading for the chance they run. Every poll is weighted by the pollster's grade. Every state gets a forecast, built from 11,111 simulated elections.

And because it started in Florida, Florida never leaves the frame: county turnout, the Legislature, and the races that shape the state.

How we keep score

No number without a reason.

Five rules every page follows.

01

Every number has a rule

Weights are written down, from 0.25 for a weak signal up to the biggest factors, and the same rule applies to every candidate.

02

Every rule has a reason

Each weight comes with the evidence behind it, from past elections to how much early polls tend to miss.

03

Every source is linked

Polls, news and filings link back to where they came from, so anyone can check the work.

04

History isn't rewritten

Each day's reading is saved as it was. Changing a weight later changes today, not the past.

05

Polls are graded

A polls count fully, B 0.85, C 0.65, D 0.25. Each pollster's latest poll from the last 30 days counts once.
